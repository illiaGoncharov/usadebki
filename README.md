# Усадебки

> Открытая картотека русских усадеб: официальный реестр объектов культурного наследия, статьи Википедии, архивные фотографии и интерактивная карта в едином каталоге.

В государственных реестрах тысячи усадеб лежат сухими строками: без фотографий, без точных координат и без понимания, уцелел ли главный дом. Проект «Усадебки» задуман, чтобы вернуть этим местам объём — собрать разрозненные записи реестра в цельные ансамбли, обогатить их открытыми знаниями и дать возможность дополнять досье по книгам и краеведческим источникам.

Живая бета: [usadebki-beta.vercel.app](https://usadebki-beta.vercel.app/)

---

## Как это устроено

- **Каркас из ЕГРОКН**: импорт открытых данных Минкультуры России (100k+ записей) с автоматической реконструкцией графа ансамблей (главные дома, флигели, парки, церкви).
- **Обогащение из открытых источников**:
  - **Wikidata SPARQL**: архитекторы, владельцы, стили, датировки, привязка QID.
  - **Wikimedia Commons**: свободные исторические и современные снимки с полной атрибуцией лицензий.
  - **Русская Википедия**: контекст и исторические справки.
  - **Паспорта ЕГРОКН**: резервные справочные данные для объектов без статей.
- **Интерфейс**:
  - Быстрая бесконечная лента с сохранением позиции скролла при переходе в карточку.
  - Легковесная карта на MapLibre GL со светлой подложкой CARTO.
  - Фильтры по регионам, историческим губерниям, векам, стилям, состоянию и удалённости от городов.
- **Краудсорсинг**: форма уточнения с обязательным указанием источника (книга, архивный документ, ссылка).

## Стек

- **Фреймворк**: Next.js 16 (App Router), React 19, TypeScript
- **База данных**: PostgreSQL (Neon в проде / Docker локально), Drizzle ORM
- **Карты**: MapLibre GL + CARTO basemaps (серверный ключ)
- **Стилизация**: чистый семантический CSS без тяжелых UI-фреймворков

## Быстрый старт

### 1. Окружение

Создайте `.env` на основе примера:

```bash
cp .env.example .env
```

Отредактируйте параметры:
- `DATABASE_URL` — строка подключения к PostgreSQL (локальный порт `5434` или Neon)
- `CARTO_KEY` — ключ светлой подложки [CARTO Basemaps](https://carto.com/basemaps/apikey)
- `ADMIN_PASSWORD` и `ADMIN_SECRET` — пароль и секрет для модерации правок (`/admin`)

### 2. Запуск локальной базы и приложения

```bash
# Установка зависимостей
npm install

# Запуск PostgreSQL в Docker
npm run db:up

# Применение миграций схемы
npm run db:migrate

# Запуск в режиме разработки
npm run dev -- --port 3010
```

Приложение откроется на [http://localhost:3010](http://localhost:3010).

## Скрипты работы с данными

| Команда | Описание |
|---------|----------|
| `npm run import:egrkn` | Скачивание и двухпроходный импорт архива ЕГРОКН: поиск усадеб, сборка графа ансамблей и сохранение паспортов |
| `npm run enrich:all` | Обогащение всех регионов: координаты, статьи Википедии, снимки Commons, архитекторы и владельцы из Wikidata, справки ЕГРОКН |
| `ENRICH_REGION=50 npm run enrich:all` | Обогащение конкретного региона (например, 50 — Московская область) |
| `npm run photos:audit` | Проверка фото: скрывает чужие, выбирает проверенное главное (пробный запуск; `-- --apply` применяет, `-- --restore=ФАЙЛ` откатывает) |
| `npm run photos:test` | Тесты правил сопоставления фото |
| `npm run enrich:stats` | Сводная статистика покрытия: % усадеб с фото, с текстом, разбивка по источникам и регионам |
| `npm run db:dump` | Создание локального дампа базы (`data/usadebki.dump`) |
| `npm run db:push-neon` | Восстановление дампа в Neon **без** `--clean` (осторожно: повторная заливка не заменяет данные и не чинит схему) |
| `npm run db:migrate:neon` | Только миграции Drizzle на Neon, данные не трогаем |
| `npm run db:sync-neon` | Устаревший цикл: `db:dump` + `db:push-neon` — для беты лучше `beta:publish` |
| `npm run beta:publish` | Обновление **контента** беты: дамп → `pg_restore --clean` в Neon → проверка колонок и HTTP 200 |

**Обновить фото на бете** (без редеплоя кода): после проверки правил локально — `npm run photos:audit -- --apply`, затем `npm run beta:publish`. В шапке карточки только одно подтверждённое фото главного здания; пустая шапка лучше, чем чужой снимок. Если менялся код — отдельно `git push` в ветку Vercel.
